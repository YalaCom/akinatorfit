# Складской Акинатор — версия 2

Игра для телефона и Telegram Web App. 38 подтверждённых сотрудников, 174 вопроса.

Открыть: https://yalacom.github.io/akinatorfit/

Запуск локально: откройте index.html через локальный HTTP-сервер, например python -m http.server 8000. Для проверки движка: node tests/engine.test.js.

Пять ответов: да, скорее да, не знаю, скорее нет, нет. Неизвестные признаки не считаются отрицательными. Вопросы выбираются по вероятностной полезности, есть отмена ответа, уточнения и продолжение после неверной догадки. Автоматический поиск ограничен 30 вопросами, после чего возможна точная проверка кандидатов. Абсолютная точность при неполной базе не гарантируется.

В публичной базе оставлены игровые признаки. Исходный полный документ с личными сведениями коллег не входит в репозиторий. Не следует публиковать дополнительные личные данные без согласования с их владельцами.

Исходники: data.js, data-v2.js, engine.js, app.js, index.html, styles.css. Изображения — пользовательские, оптимизированы для мобильной страницы.
